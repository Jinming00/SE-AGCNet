# AGC Dataset Generation

Generate multi-speaker audio combinations for AGC speech enhancement training.

## Datasets

- **LibriTTS**: https://www.openslr.org/60/
- **VoiceBank-Demand(use '28spk')**: https://datashare.ed.ac.uk/handle/10283/2791  

## Requirements

```bash
pip install numpy librosa soundfile tqdm pandas
```

## Usage

### LibriTTS

```bash
python LibriAGC_gen.py \
    --data_dir /path/to/LibriTTS \
    --output_dir /path/to/output \
    --mode test  # or train
```

Or use the script:
```bash
bash run_libriagc_gen.sh
```

### VoiceBank-Demand

```bash
python VoiceBankAGC_gen.py \
    --data_dir /path/to/voicebank-demand \
    --output_dir /path/to/output
```

Or:
```bash
bash run_voicebank_gen.sh
```

### Add DNS noise to lower audio

After generating a dataset, add random DNS noise to the wav files in `lower/`:

```bash
python add_noise_to_lower.py \
    --lower_dir /path/to/output/train_5_30/lower
```

Or use the script:
```bash
bash run_add_noise_to_lower.sh
```

Defaults:
- Noise directory: `/projects_vol/gp_aseschng/jinming/data/NOISE/DNS_for_SE-AGCNet`
- SNR range: 5-25 dB
- Output directory: sibling directory named `lower_noisy`
- Metadata: `lower_noisy/noise_metadata.csv`

## How it works

Concatenates 2-5 clips from different speakers:

| Directory | Content |
|-----------|---------|
| origin/ | Raw concatenation |
| lower/ | Some clips reduced to 5-30% volume, with augmentation |
| lower_noisy/ | `lower/` audio mixed with DNS noise at random 5-25 dB SNR |

Augmentation (15% each):
- Sudden spikes (2-5x volume)
- Gradual increase
- Gradual decrease
- Volume fluctuation (sine wave)

## Output

```
{output_dir}/{mode}_5_30/
├── origin/
├── lower/
├── lower_noisy/      # Optional, generated by add_noise_to_lower.py
├── transcriptions/   # LibriTTS only
├── rttm/             # LibriTTS only
└── metadata/
```
